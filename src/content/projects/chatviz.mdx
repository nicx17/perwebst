## Overview

When you request your data archives from messaging services like Instagram, Snapchat, or WhatsApp, you receive gigabytes of raw JSON files, fragmented text logs, and nested media folders. Existing viewer tools require uploading these sensitive conversations to remote third-party servers.

**ChatViz solves this without compromising privacy.** All parsing, unzipping, decrypting, and rendering executes 100% on the client. Outbound network communication is blocked at the browser level through a strict Content Security Policy.

## Supported Export Formats

### 1. Instagram (`message_*.json`)

- **Mojibake UTF-8 Repair**: Resolves Instagram's longstanding export bug where Unicode text (emojis, accented characters) is encoded as broken Latin-1 byte escapes (e.g. `\u00c3\u00a9` decoded to clean characters).
- **Multi-File Thread Stitching**: Automatically merges split sequential files (`message_1.json`, `message_2.json`) into single chronological conversation threads.
- **Inline Reactions**: Renders Instagram reaction notifications as compact interactive emoji pills overlaid on the target message bubble.

### 2. Snapchat (`chat_history.json`)

- Ingests the full conversation tree rather than just the single largest thread.
- Maps ephemeral media notices, text messages, and timestamped shared stories.

### 3. WhatsApp (`.txt` and `.zip`)

- **Zip64 Random-Access Reader**: Opens multi-gigabyte WhatsApp `.zip` archives directly using range slices from the local `File` handle, streaming photos, videos, voice notes, and stickers on demand without exhausting device memory.
- **Universal Date & Time Parsing**: Automatically identifies 12-hour/24-hour clocks and ambiguous month/day ordering based on entire log context.

<ArchitectureSection title="Client-Side Pipeline Architecture">
  <ChatVizArchitecture />

- **Dedicated Web Worker**: File parsing and unzipping run off the main thread inside an inline `blob:` worker. Heavy multi-megabyte JSON trees are transformed into lightweight normalized schemas without freezing UI interaction.
- **HMAC-Blinded Database Keys**: Chat IDs and participant names in IndexedDB are indexed through HMAC hashes derived from your master passphrase, preventing forensic inspection of database keys even if the browser disk storage is inspected.
- **Volatile Key Lifecycles**: Passphrase stretching yields an AES-GCM encryption key that exists exclusively in memory. Pressing **Lock**, refreshing, or closing the tab drops the key reference.
- **Streaming Media Extraction**: Rather than unzipping entire multi-gigabyte archives into RAM, the zip parser reads directory records from the end of the file and extracts individual image/audio blobs only when scrolled into view.

</ArchitectureSection>

## Cryptographic Security Model

ChatViz treats browser storage as untrusted and implements defense-in-depth:

| Security Layer         | Implementation Details                                                                          |
| :--------------------- | :---------------------------------------------------------------------------------------------- |
| **Key Derivation**     | PBKDF2-SHA256 with 600,000 iterations and a unique 16-byte cryptographic salt per vault.        |
| **Message Encryption** | AES-256-GCM authenticated encryption for message text, participant names, and media blobs.      |
| **Key Blind Hashing**  | HMAC-SHA256 obscures search terms and primary keys inside IndexedDB stores.                     |
| **Network Air Gap**    | `connect-src 'none'`, `object-src 'none'`, `form-action 'none'`, and `frame-ancestors 'none'`.  |
| **Link Defense**       | External links require explicit confirmation dialogs and open with `rel="noreferrer noopener"`. |
| **Ephemeral Session**  | "View without saving" mode keeps chats in transient memory and clears all data on tab close.    |

## Technology Stack

### Frontend & UI

- **Framework**: React 19 / Vite 8
- **Styling**: Tailwind CSS v4 with custom property tokens
- **Virtualization**: `@tanstack/react-virtual`
- **Icons**: `lucide-react`
- **Typography**: Bricolage Grotesque (display headline), Inter (interface text)

### Parsing & Cryptography

- **Off-Thread Processing**: Dedicated Web Worker (`src/workers/parseWorker.js`)
- **Zip Extraction**: `fflate` with random-access slice reader
- **Encryption**: WebCrypto API (`SubtleCrypto` PBKDF2, AES-256-GCM, HMAC)
- **Local Storage**: IndexedDB via `idb`

### Hosting & Deployment

- **Platform**: Cloudflare Workers Static Assets (`wrangler.jsonc`)
- **Static Delivery**: Zero server-side runtime code; pre-compiled static bundle
- **Security Headers**: Edge-enforced CSP, HSTS, frame-ancestors 'none', and referrer-policy via `_headers`
